How can we help?

Installation guidance, troubleshooting steps, permission explanations, and direct feedback options.

Getting started

  1. Add Meisai to your browser (__AVAILABILITY_NOTE__) and open a new tab.
  2. Complete the short first-time setup with your name and an optional learning goal, either step can be skipped.
  3. Use Home to add tasks, notes, habits, upcoming events, or a focus statement.
  4. Press Ctrl + K (or Cmd + K) anywhere inside Meisai to open the command palette.
  5. On a supported webpage, use the floating Meisai Helper for saving, reading, capture, and note actions.

Troubleshooting

Meisai shows a local data error
Reload the extension from about:addons in Firefox or chrome://extensions in Chrome or Brave, then reopen a new tab. Your existing local data is not affected by the error screen. If it continues, include the error text in a feedback report.
The Meisai Helper is missing on a page
Browsers block extensions from running on protected internal pages and extension-store pages. Test on a normal HTTP or HTTPS page, and reload that page after reloading Meisai.
Screenshot capture isn't working
Open Meisai Helper from a normal webpage and confirm the extension is enabled for that site, then retry. Capture is not available on protected internal pages.
Website blocking isn't active
Blocking only runs while a Pomodoro focus session is in progress. Add domains under Settings → Website Blocking, then start the focus timer.
Notifications don't appear
Enable the notification categories you want in Settings → Privacy & Data, and confirm notifications are allowed for your browser at the operating-system level.

Why Meisai requests permissions

  • Storage: saves lightweight preferences such as theme, wallpaper, and layout.
  • Alarms & notifications: keeps Pomodoro timing and selected reminders running in the background.
  • Side panel: provides Meisai from the browser's side-panel surface.
  • Active tab & scripting: runs your requested capture actions and restores Meisai Helper on already-open supported tabs.
  • Declarative Net Request: blocks only the sites you configure, only during an active focus session.
  • HTTP/HTTPS page access: powers Meisai Helper, Reading Mode, page capture, and configured website blocking.
  • Bookmarks & history (optional): adds local command-palette suggestions only if you enable it; each source can be turned off independently.

Read the full privacy policy for how each permission is used.

Backup and restore

Open Settings → Privacy & Data to export everything, or a single area such as planning, notes and Knowledge Vault, reading, or career data. Keep the JSON backup file somewhere safe. The same page can preview a backup file and restore it in merge or replace mode, and delete one data category without clearing the rest of Meisai.

Tip: export a fresh backup before clearing browser data, uninstalling the extension, or using replace-mode restore.

Frequently asked questions

What is Meisai?
Meisai is a personal workspace that adds planning, capture, knowledge, reading, focus, and career tools to the browser you already use.
Is Meisai a browser?
No. Meisai is a workspace layer delivered through your browser. It doesn't replace your browser's web engine or your normal browsing experience.

Where is my data stored?
Currently, core workspace data is stored locally on your device, in your browser's local storage.
Do I need an account?
No. Core features work without signing up or creating an account.
Does Meisai sync across devices?
Not yet. Meisai currently stores your workspace locally. Cross-device cloud sync is planned for a future version.
Is Meisai free?
Yes, free while Meisai grows. There's no paid tier today.
Can I customize the workspace?
Yes. You can resize, rearrange, show, and hide supported widgets, and restore the default layout any time.
Can I use Meisai for career organization?
Yes, through Resume Hub, Portfolio, and Job Tracker, all part of the current workspace.
