Getting started

  1. Add Meisai to Chrome and open a new tab.
  2. Complete the first-time setup with your name and optional learning goal.
  3. Use Home to add tasks, notes, habits, upcoming events, or a focus statement.
  4. Press Ctrl + K or Cmd + K anywhere inside Meisai to open the command palette.
  5. On a supported website, use the page-edge Meisai Helper for reading, capture, and note actions.

Troubleshooting

Meisai shows “Local data error”

Reload the extension from chrome://extensions, then reopen the new tab. Existing local data is not changed by the error screen. If the issue continues, open the extension service-worker console and include the error in a feedback report.

The Meisai Helper is missing

Chrome prevents content scripts on protected pages such as chrome:// pages and the Chrome Web Store. Test on a normal HTTP or HTTPS webpage and reload that page after reloading the extension.

Screenshot capture is unavailable

Open Meisai from a normal webpage, ensure the extension is enabled for that site, and retry the capture. Chrome does not permit capture on protected browser pages.

Website blocking is not active

Blocking starts only while a Pomodoro focus session is running. Add domains under Settings → Website Blocking, then start the focus timer.

Notifications do not appear

Enable the desired notification categories in Settings → Privacy & Data and allow notifications for Chrome in the operating system.

Why Meisai requests permissions

  • StorageSaves lightweight extension preferences such as themes, helper position, and notification choices.
  • Alarms & notificationsKeeps timers, countdown reminders, and selected notifications working through the extension service worker.
  • Side panelProvides Meisai from Chrome's side-panel surface.
  • Active tab & scriptingRuns user-requested capture and restores the visible Meisai Helper on supported tabs.
  • Declarative Net RequestBlocks only the websites the user configures while a focus session is active.
  • HTTP/HTTPS page accessPowers the visible helper, Reading Mode, selected-page capture, and configured website blocking on normal webpages.
  • Bookmarks & history (optional)Provides local command-palette suggestions only when individually enabled by the user.

Backup and restore

Open Settings → Privacy & Data to export a local JSON backup. Keep that file somewhere safe. The same page can preview and restore a backup in merge or replace mode.

Always export a fresh backup before clearing browser data, uninstalling the extension, or using replace-mode restore.

Feedback & suggestions

Report a problem, suggest a feature, or tell us what helps. Please include the Meisai version, Chrome version, the page where the issue occurred, and clear reproduction steps when reporting a bug.
