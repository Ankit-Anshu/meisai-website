Privacy at Meisai

Privacy Policy

Effective August 2, 2026. This policy explains the current version of Meisai and the controls available to users.

Overview

Meisai is a browser extension for learning, reading, productivity, and career organization on Google Chrome, Microsoft Edge, and Brave. This policy explains what information the current version handles, where it is stored, and how users control it.

Current version: Meisai does not sell user data, serve advertising, or include third-party analytics.

Data Meisai handles

Depending on the features a user chooses, Meisai may handle:

  • A local display name and profile image.
  • Notes, tasks, habits, calendar events, countdowns, projects, job applications, interview details, resumes, and learning resources.
  • Saved page URLs, readable article content, screenshots, images, links, text, and code.
  • Reading progress, highlights, and comment notes.
  • A manually selected weather location.
  • Optional browser bookmarks or history used locally for command suggestions.

How data is stored

Persistent user content is stored locally on the user's device in IndexedDB. Lightweight interface preferences use the browser's extension storage API, exposed as chrome.storage.local across supported Chromium browsers. Meisai does not operate a server that receives this local workspace data.

Network requests

Meisai makes network requests only for user-facing features. Examples include loading a selected webpage for Reading Mode, opening a saved link, retrieving weather and air-quality data from Open-Meteo, submitting feedback through the published Google Form, or sending a search query to the user's selected search provider. Those services process requests under their own privacy policies.

Browser permissions

Supported-page access powers the visible Meisai Helper, user-initiated screenshot and reading actions, and user-configured website blocking. Bookmark and history permissions are optional and requested only when their command-suggestion settings are enabled. Information obtained through these permissions is processed locally for the requested feature.

See the permission guide for a plain-language explanation of each permission.

Sharing, advertising, and analytics

Meisai does not sell user information, share it for advertising, use it for personalized advertising, or include third-party analytics. The developer does not permit humans to read a user's locally stored content.

User control and retention

Data remains on the user's device until it is edited, deleted, cleared through Meisai's Privacy & Data controls, removed with the extension, or erased by the browser. Users can export a local backup and restore it later. Notification categories and optional browser-data suggestions can be disabled in Settings.

Security

Meisai uses Manifest V3, packages executable code with the extension, validates stored records, and sanitizes supported rich content before rendering. User-requested external connections use HTTPS when the destination supports it.

Changes to this policy

Material changes to this policy or Meisai's data practices will be reflected here and in relevant browser-extension store disclosures. The effective date at the top of this page will be updated.

Contact

For privacy questions, bug reports, or suggestions, use the Meisai feedback form or visit Help & Support.
